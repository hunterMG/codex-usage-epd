# codex-usage-epd 2026.10.2

Released 2026-10-30.

This release improves the first-run experience and adds guardrails around
continuous integration and PyPI publishing.

## Highlights

- Reworked the README for end users, with clearer installation, quick-start,
  command, configuration, and launchd instructions.
- Added a copy-and-paste prompt for installing the project with a coding agent.
- Added a CI workflow and status badge, and documented supported Python
  versions through 3.15.
- Pinned the release workflow's GitHub Actions to valid, stable refs before
  publishing to PyPI.

## Upgrade

Upgrade with the tool you used to install the package:

```sh
pipx upgrade codex-usage-epd
uv tool upgrade codex-usage-epd
pip install --upgrade codex-usage-epd
```

There are no configuration changes required for this release.
